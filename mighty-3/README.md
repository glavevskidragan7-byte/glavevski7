# MIGHTY PROJECT — 3 MESECA

PWA za praćenje treninga, 90 dana — plan za rast mišića.
Raspored: Pon gornji deo A, Uto donji deo A + džak 15 min, Sre odmor, Čet gornji deo B, Pet donji deo B + džak 15 min, Sub i Ned odmor.
Supersetovi (A1+A2, B1+B2, pa C), 2 serije – prva sa 1–2 ponavljanja u rezervi, druga do otkaza. Svaki mesec teže varijante.
Za svaku seriju upisuješ broj ponavljanja; aplikacija pokazuje šta si uradio isti dan prethodne nedelje.
Objava: prevuci folder `mighty-3` na Netlify (Deploys postojećeg sajta), otvori link u Chrome-u → ⋮ → Instaliraj aplikaciju.
