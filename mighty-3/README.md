# MIGHTY PROJECT — 3 MESECA

PWA za praćenje treninga, 90 dana.
Raspored: Pon trening 1, Uto džak 15 min, Sre trening 2, Čet odmor, Pet trening 3, Sub džak 15 min, Ned odmor.
Svaki trening: 4 vežbe celo telo, 2 serije do otkaza (~20 min). Varijante A/B se smenjuju svake nedelje, svaki mesec teža verzija vežbi.
Za svaku seriju upisuješ broj ponavljanja; aplikacija pokazuje šta si uradio na istom treningu pre 2 nedelje.
Objava: prevuci folder `mighty-3` na Netlify (Deploys postojećeg sajta), otvori link u Chrome-u → ⋮ → Instaliraj aplikaciju.
