# MIGHTY PROJECT — 3 MESECA

PWA za praćenje treninga, 90 dana, svaki mesec teže. Raspored: Pon leđa, Uto grudi i stomak, Sre džak 15 min, Čet noge, Pet ruke i ramena, Sub odmor, Ned džak 15 min.
Objava: prevuci folder `mighty-3` na https://app.netlify.com/drop, otvori link u Chrome-u na telefonu → ⋮ → Instaliraj aplikaciju.
