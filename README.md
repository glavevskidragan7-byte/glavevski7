# MIGHTY PROJECT — MONTH 1

Jednostavna PWA aplikacija za praćenje treninga (30 dana). Radi bez interneta posle instalacije, napredak se čuva u telefonu (localStorage).

Fajlovi: `index.html`, `style.css`, `app.js`, `manifest.webmanifest`, `sw.js`, ikonice.

## Objavljivanje (besplatno, GitHub Pages)
1. GitHub → ovaj repo → **Settings → Pages**.
2. Source: **Deploy from a branch**, izaberi granu sa aplikacijom i folder `/ (root)` → Save.
3. Posle 1–2 minuta adresa je `https://<korisnik>.github.io/<repo>/`.

## Instalacija na Android
Otvori adresu u **Chrome-u** → meni ⋮ → **Instaliraj aplikaciju** (ili „Dodaj na početni ekran“).
